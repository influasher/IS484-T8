AZURE WEB APP DEPLOYMENT (Current Focus)
================================================================================

ISSUE: Web App showing "ImagePullFailure" - container cannot pull from ACR

SOLUTION STEPS:
1. Fix ACR Authentication:
   ```bash
   # Check ACR admin access
   az acr show --name sentifinancetwo --query "adminUserEnabled"
   
   # Enable if false
   az acr update --name sentifinancetwo --admin-enabled true
   
   # Get credentials
   az acr credential show --name sentifinancetwo
   ```

2. Configure Web App Container Settings:
   ```bash
   # Set correct container image and ACR credentials
   az webapp config container set \
     --name sentifinancetwo \
     --resource-group sentifinance2 \
     --container-image-name sentifinancetwo.azurecr.io/sentifinance-backend:latest \
     --container-registry-url https://sentifinancetwo.azurecr.io \
     --container-registry-user sentifinancetwo \
     --container-registry-password $(az acr credential show --name sentifinancetwo --query "passwords[0].value" -o tsv)
   ```

3. Set Required Environment Variables:
   ```bash
   az webapp config appsettings set \
     --name sentifinancetwo \
     --resource-group sentifinance2 \
     --settings \
       WEBSITES_PORT=5001 \
       FLASK_ENV=production \
       APP_DEBUG=False \
       SECRET_KEY="production-secret-$(date +%s)" \
       DATABASE_URI="sqlite:///production.db" \
       JWT_SECRET_KEY="production-jwt-$(date +%s)"
   ```

4. Restart and Test:
   ```bash
   az webapp restart --name sentifinancetwo --resource-group sentifinance2
   sleep 60
   curl https://sentifinancetwo-b6bdfrfsf0dwc9h3.southeastasia-01.azurewebsites.net
   ```

================================================================================
AKS DEPLOYMENT (Future Setup)
================================================================================

STEP 1: CREATE AKS CLUSTER
```bash
# Create AKS cluster with ACR integration
az aks create \
  --resource-group sentifinance2 \
  --name sentifinance-aks \
  --node-count 2 \
  --node-vm-size Standard_B2s \
  --attach-acr sentifinancetwo \
  --generate-ssh-keys

# Get cluster credentials  
az aks get-credentials \
  --resource-group sentifinance2 \
  --name sentifinance-aks \
  --overwrite-existing
```

STEP 2: CREATE PRODUCTION SECRETS
```bash
# Create Kubernetes secrets (DO NOT commit to Git!)
kubectl create secret generic sentifinance-secrets \
  --from-literal=secret-key="$(openssl rand -hex 32)" \
  --from-literal=database-uri="sqlite:///production.db" \
  --from-literal=jwt-secret-key="$(openssl rand -hex 32)"
```

STEP 3: DEPLOY APPLICATION
```bash
# Deploy using kubectl
kubectl apply -f k8s/

# Check deployment status
kubectl get pods -n sentifinance
kubectl get services -n sentifinance

# Wait for LoadBalancer IP
kubectl get service sentifinance-service -n sentifinance -w
```

STEP 4: UPDATE GITHUB SECRETS FOR AKS
```bash
# Set AKS cluster information
gh secret set AKS_CLUSTER_NAME --body "sentifinance-aks"
gh secret set AKS_RESOURCE_GROUP --body "sentifinance2"

# Get LoadBalancer IP after deployment and set it
LOADBALANCER_IP=$(kubectl get service sentifinance-service -n sentifinance -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
gh secret set AKS_LOADBALANCER_IP --body "$LOADBALANCER_IP"
```

STEP 5: TEST AKS DEPLOYMENT
- Go to GitHub Actions → "Deploy to Azure Kubernetes (K8s)" → "Run workflow"

================================================================================
TROUBLESHOOTING
================================================================================

WEB APP ISSUES:
- 503 Service Unavailable → Wrong port or missing env vars
- ImagePullFailure → ACR authentication issue
- Application Error → Check app logs: az webapp log tail

AKS ISSUES:
- Pods not starting → Check: kubectl describe pod <pod-name>
- Image pull errors → Verify ACR attachment: az aks show --query addonProfiles.acrProfile
- Service not accessible → Check: kubectl get services

COMMON FIXES:
- Restart services: az webapp restart / kubectl rollout restart deployment
- Check logs: az webapp log download / kubectl logs
- Verify secrets: az webapp config appsettings list / kubectl get secrets
